# Downeast Ice Cream Factory logos

Vector redraw of `reference/downeast-badge-original.png` (the owner's chosen design).

| File (`svg/`) | Use |
|---|---|
| `downeast-badge.svg` | Primary logo: signs, cups, merch, stickers, website footer |
| `downeast-horizontal.svg` / `-on-dark.svg` | Wide spaces: letterhead, email, menus, banners |
| `downeast-header.svg` / `-on-dark.svg` | Small spaces (legible at ~48 px tall): website header |
| `downeast-icon.svg` | Round icon: favicon, social avatar, app icon |
| `downeast-mark.svg` | Scoop on cone only: stamps, patterns, accents |

PNG exports are in `png/` (badge 1200 px, icon 512/64/32/16 px, Apple touch icon 180 px).

**Give printers and sign makers the SVG files.** They scale to any size without blurring. All text is converted to outlines, so no fonts are needed.

## Editing

All artwork is generated by `build-logos.mjs` (colors at the top in `COL`). After changes:

```bash
npm install
node build-logos.mjs   # writes svg/
node render.mjs        # writes png/ (needs Google Chrome)
```

Then copy `svg/*.svg` (and the badge/icon PNGs) to `site/public/brand/`, `svg/downeast-icon.svg` to `site/src/app/icon.svg`, and `png/apple-touch-icon.png` to `site/src/app/apple-icon.png`.
