# Downeast Ice Cream Factory: website redesign

Redesign of [downeasticecreamfactory.com](https://downeasticecreamfactory.com), a super premium ice cream maker in Boothbay Harbor, Maine, since 1979.

| Folder | What's inside |
|---|---|
| [`site/`](site/) | The website: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Motion, and a real-time 3D hero cone (Three.js / React Three Fiber). See [`site/README.md`](site/README.md). |
| [`brand/`](brand/) | Logo family as vector SVG + PNG exports, and the script that builds them. See [`brand/README.md`](brand/README.md). |
| [`harbor-cone-r3f/`](harbor-cone-r3f/) | Standalone prototype of the 3D cone (art-direction reference). |
| [`previews/`](previews/) | Screenshots and renders from the design process. |

## Run the website

```bash
cd site
npm install
npm run dev     # http://localhost:3000
```
